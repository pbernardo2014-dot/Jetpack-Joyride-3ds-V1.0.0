# Jetpack Joyride 3DS (LPP-3DS) - v1.0.0

Un fan-porting in Lua di **Jetpack Joyride** sviluppato per Nintendo 3DS utilizzando l'engine **LPP-3DS** (Lua Player Plus 3DS).

## 🚀 Caratteristiche
* Movimento e fisica del jetpack adattati per 3DS.
* Generazione casuale di ostacoli (Zapper) e monete.
* Aumento progressivo della velocità ogni 50 metri.
* Contatore digitale a 7 segmenti per metri e monete.
* Sistema di salvataggio/riavvio rapido e gestione sicura del frame buffer.

## 🎮 Comandi
* **A**: Attiva il Jetpack (spinta verso l'alto)
* **X**: Riavvia la partita (dalla schermata di Game Over)
* **START**: Esci dal gioco
* **Y**: Attiva il server FTP (nella schermata di errore/debug di LPP-3DS)

## 📥 Installazione
1. Scarica e installa **LPP-3DS** sulla tua console Nintendo 3DS (tramite Homebrew Launcher o Custom Firmware).
2. Copia il file `index.lua` all'interno della cartella del gioco sulla SD della console (o trasferiscilo via FTP).
3. Avvia LPP-3DS per giocare!
